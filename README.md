**IA Invaders**
2026. AI writes all the code. Nobody reviews it.
Bugs are multiplying, commits ship unchecked, and one person is still standing: **Fred, the last human developer**, armed with his PB Compiler pistol.

A Space Invaders clone with an LGTM twist. The armada of Bugs, Code Knots and Git Commits comes down line by line. Blast them all before the system crashes.

**Enemies**: Bugs, Code Knots (2 hits), Git Commits (when they die, a merge conflict speeds up the armada).  
**CEO $$$**: crosses the top of the screen. It takes 3 hits, and the armada goes up one line. It also drops a rubber duck for a shield (rubber duck debugging, finally useful).  
**MegaCenter**: flies just below the armada and throws lightning. Let it escape and the armada goes down one line.  
**Fixed by AI**: killing a Bug can bring another one back. The AI fixes things, its own way.  
**Hallucinations**: some shots (the cyan ones) aren’t real. If you can spot them.  
**The ending**: if you lose, the AI offers to restore the backup. If you win, it wants to say LGTM too.  

5 waves, 5 lives, arrows to move, Space to fire.

***100 % pure PureBasic***, no API, no external library, made for PurePunch Halloween 2026. It compiles, it passes, 0 tests, nobody knows why.
